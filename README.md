# Hello World — Java 17 + Maven + Groovy + Spock

A tiny project with **no database**. Application class is Java 17; tests are Groovy/Spock.

## Requirements
- JDK 17 (or newer JDK configured to compile as Java 17)
- Apache Maven 3.9+ (installed or available in IntelliJ)
- IntelliJ IDEA with Java and Groovy support

## IntelliJ IDEA
1. Extract this ZIP.
2. IntelliJ -> **File > Open** -> select the extracted project folder or `pom.xml` -> **Open as Project**.
3. Set **File > Project Structure > Project SDK** to **JDK 17**.
4. Check **Settings > Build, Execution, Deployment > Build Tools > Maven > Runner > JRE** is JDK 17.
5. In Maven tool window, click **Reload All Maven Projects** and allow dependencies to download.
6. Open `src/test/groovy/com/example/HelloWorldSpec.groovy`.
7. Click the green Run arrow next to `class HelloWorldSpec` (or each feature method). Alternatively run the Maven `test` lifecycle goal.

## Command line
```bash
mvn clean test
mvn surefire-report:report-only
```

## Reports
- Test XML and text: `target/surefire-reports/`
- HTML report: `target/site/surefire-report.html` (generated by Maven Surefire Report Plugin).

## Source layout
- `pom.xml` — dependencies, Groovy test compiler, Maven Surefire runner, report plugin
- `src/main/java/com/example/HelloService.java` — Java code
- `src/test/groovy/com/example/HelloWorldSpec.groovy` — Spock tests: `given`, `when`, `then`, `expect`, `where`, `@Unroll`

If IntelliJ does not display Groovy syntax highlighting, enable its bundled Groovy plugin.
